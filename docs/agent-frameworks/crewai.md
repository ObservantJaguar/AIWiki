# CrewAI

CrewAI is a Python framework for orchestrating role-based multi-agent teams. You define agents with roles, goals and tools, and a crew works through tasks together — a popular, approachable way to build multi-agent systems.

## Overview

- **Language**: Python
- **License**: MIT
- **Developer**: CrewAI (open source)
- **Status**: active, fast-growing; parts moved to a commercial platform

## Key features

- **Role-based agents**: each agent has a role, goal, backstory and tool set.
- **Crews and tasks**: sequence/parallel tasks delegated to appropriate agents.
- **Flows**: event-driven control of agent processes.
- **Tool integration**: connects to LangChain tools, custom tools and local/remote models.
- **Self-hostable**: runs on local models (Ollama, vLLM) and open embeddings.
- **Output control**: structured and file-based agent outputs.

## Best for

- Multi-agent workflows such as research, drafting and review pipelines.
- Teams that want a higher level of orchestration than raw agent SDKs.
- Building "crew" style applications quickly.
