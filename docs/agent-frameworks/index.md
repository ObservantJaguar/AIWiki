# Agent frameworks and LLM application libraries

Frameworks for building applications on top of LLMs — from RAG pipelines to multi-agent systems. They provide the plumbing: model calls, retrieval, tools, orchestration.

- [LangChain](langchain.html) — the most popular LLM application framework.
- [LlamaIndex](llamaindex.html) — data-centric RAG framework.
- [CrewAI](crewai.html) — role-based multi-agent orchestration.
- [AutoGen](autogen.html) — multi-agent conversation framework (Microsoft).
