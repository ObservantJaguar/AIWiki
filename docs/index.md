# AI Wiki

A self-hosted, open-source encyclopedia of **neural networks, machine learning and artificial intelligence** for engineers, DevOps specialists and developers.

The wiki is organized into three classes:

- **Theory** — the concepts behind deep learning: how models learn, the transformer architecture, model families, training, inference, benchmarking and safety.
- **Tools** — an encyclopedia of software: runtimes, LLM servers, vector databases, finetuning libraries, multimodal generators and agent frameworks.
- **Practice** — hands-on guides for running, serving, finetuning and deploying models on your own hardware.

The focus is on **open-source and self-hostable** technology. Proprietary models and services are included and clearly marked, because they are part of the industry, but the emphasis is on software you can run yourself.

Start with the [Theory](sections/theory.html) section, or jump straight to [Tools](sections/tools.html) if you want to run something today.
