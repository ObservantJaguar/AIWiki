# ML / DL fundamentals

The building blocks of machine learning and deep learning: how a machine learns from data, the biological and mathematical idea of a neuron, how layers compose into networks, and the optimization procedures that train them.

The rest of the wiki assumes these concepts. Start with the [neuron and layers](neuron-layers.html), then read about [gradient descent](gradient-descent.html), [activation functions](activation-functions.html) and the [learning pipeline](learning.html).
