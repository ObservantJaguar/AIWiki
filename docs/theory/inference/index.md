# Inference

Running a trained model to produce outputs — the opposite of training. Practical inference is about latency, throughput and fitting a large model into limited memory.

Read about [the inference fundamentals](inference-basics.html), [model quantization](quantization.html), the [KV-cache](kv-cache.html) and serving strategies such as [batching](batching.html).
