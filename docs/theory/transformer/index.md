# Transformer architecture

The transformer is the neural architecture behind virtually every modern large language model. Introduced in 2017, it replaced recurrent networks by processing an entire sequence in parallel through **attention** instead of sequentially.

Read about [attention and self-attention](attention.html), [positional encoding](positional-encoding.html) and how the pieces compose into the [transformer block](block.html).
