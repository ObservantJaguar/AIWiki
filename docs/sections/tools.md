# Tools

An encyclopedia of open-source and self-hostable software for working with neural networks: the runtimes that execute models, the servers that expose them, the vector databases for retrieval, the libraries for finetuning, the generators for images and audio, and the frameworks for building agent-based applications.

```text
+---------------------------------------------------------------+
| Tools                                                        |
|                                                               |
| runtimes          - PyTorch, TensorFlow, JAX, ONNX Runtime    |
| llm-servers       - Ollama, vLLM, TGI, LocalAI, llama.cpp     |
| embeddings        - Qdrant, Weaviate, Milvus, Chroma, FAISS   |
| finetuning        - PEFT, axolotl, unsloth, DeepSpeed, TRL    |
| multimodal        - Stable Diffusion, ComfyUI, Whisper, Bark  |
| agent-frameworks  - LangChain, LlamaIndex, CrewAI, AutoGen    |
| observability     - MLflow, W&B, experiments, metrics         |
+---------------------------------------------------------------+
```
