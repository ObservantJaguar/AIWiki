# Practice

Hands-on guides that show how to run open-source AI on hardware you control: from downloading and running a model locally, to serving it for an application, to finetuning it on your own data.

```text
+---------------------------------------------------------------+
| Practice                                                     |
|                                                               |
| guide-ollama  - run an LLM locally with Ollama               |
| guide-vllm    - serve a model with an OpenAI-compatible API   |
| guide-rag     - build a retrieval-augmented generation app    |
| guide-lora    - finetune a model with LoRA on your dataset    |
| guide-sd      - generate images with Stable Diffusion         |
| guide-whisper - transcribe audio with Whisper                 |
+---------------------------------------------------------------+
```
