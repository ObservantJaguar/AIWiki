# Bark

Bark is an open-source, transformer-based text-to-audio model. It generates highly realistic speech, and can also produce music, sound effects and other non-verbal audio, making it a versatile self-hostable audio tool.

## Overview

- **Type**: open-source text-to-audio model
- **License**: MIT (code); model is Apache-2.0
- **Developer**: Suno (open source — the codebase was released; note the licensing)
- **Status**: produced impressive results; development activity has slowed relative to newer TTS

## Key features

- **Text-to-speech**: very natural, emotive speech in multiple languages.
- **Non-verbal audio**: can output music and simple sound effects from text.
- **Voice control**: presentations of speaker and style can be steered.
- **Local-first**: runs on CPU/GPU with PyTorch and Hugging Face transformers.
- **Self-hosted**: weights are downloadable and runnable locally without API calls.

## Best for

- Generating speech and simple audio locally for prototypes and content.
- Indie TTS use cases needing low licensing friction.
