# AUTOMATIC1111 (Stable Diffusion WebUI)

AUTOMATIC1111 is the classic, feature-rich web interface for Stable Diffusion. For years it was the default way to run SD scripts, and it remains widely used and well-documented despite the rise of ComfyUI.

## Overview

- **Type**: self-hosted web UI
- **License**: AGPL-3.0
- **Developer**: AUTOMATIC1111 (open source)
- **Status**: stable but slower-moving; newer UIs (ComfyUI, Forge) are catching up

## Key features

- **Full text-to-image and image-to-image** interfaces.
- **Extensions**: inpainting via ControlNet, LoRA, built-in upscalers.
- **Checkpoint management**: switch models and VAE easily; merge checkpoints.
- **Huge tutorial/community base**: most SD tutorials reference this UI.
- **Web API**: a REST interface for automation.

## Trade-offs

- Simpler single-page interface than ComfyUI's graph model.
- Faster for casual/one-off generation; ComfyUI is preferred for reproducible production pipelines and lower VRAM.

## Best for

- Learning Stable Diffusion with the most documented UI.
- Casual use and feature-rich out-of-the-box workflows.
