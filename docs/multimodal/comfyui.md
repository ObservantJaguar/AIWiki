# ComfyUI

ComfyUI is a node-based interface for Stable Diffusion and other diffusion models. Users wire up a graph of nodes — prompts, models, samplers — for precise, reproducible, scriptable image-generation workflows.

## Overview

- **Type**: desktop/self-hosted web UI
- **License**: GPL-3.0
- **Developer**: Comfy (open source)
- **Status**: very active, the leading interface for advanced users

## Key features

- **Node-based graph editor**: connect models, prompts, samplers and post-processing.
- **Reproducible workflows**: share a single JSON workflow for exactly-once reproduction.
- **Low VRAM modes**: designed to run full pipelines efficiently.
- **Broad model support**: SD1.5, SDXL, SD3, Flux, plus LoRA and ControlNet.
- **Video and audio**: extensions for video (AnimateDiff, SVD) generation.
- **Extensibility**: a large custom-node ecosystem.

## Best for

- Precise control over every step of generation.
- Reusable, shareable pipelines for production or creative workflows.
- Advanced users moving beyond a simple web UI.
