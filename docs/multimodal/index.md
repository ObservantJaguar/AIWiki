# Multimodal generation (image, video, audio)

Tools for generating and processing content beyond text: image generation with Stable Diffusion, video pipelines, speech recognition with Whisper and audio generation with Bark.

- [Stable Diffusion](stable-diffusion.html) — the open image-generation model family.
- [ComfyUI](comfyui.html) — a node-based interface for diffusion models.
- [AUTOMATIC1111](a1111.html) — the classic Stable Diffusion web UI.
- [Whisper](whisper.html) — open speech recognition.
- [Bark](bark.html) — open text-to-audio generation.
