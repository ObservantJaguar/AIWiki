# Embeddings and vector databases

Tools that turn text (and other data) into vectors and search over them efficiently. They are the backbone of retrieval-augmented generation, semantic search and recommendation.

- [Embeddings models](embedding-models.html) — sentence-transformers and friends.
- [Qdrant](qdrant.html) — a high-performance Rust vector database.
- [Weaviate](weaviate.html) — a graph/REST vector database with modules.
- [Milvus](milvus.html) — a distributed, large-scale vector database.
- [Chroma](chroma.html) — a simple embedded vector store for prototypes.
- [pgvector](pgvector.html) — vector search inside PostgreSQL.
- [FAISS](faiss.html) — Meta's similarity search library.
