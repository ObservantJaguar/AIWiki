# Runtimes and frameworks

The software that executes neural networks: deep learning frameworks for building and training, and inference runtimes for running models efficiently on CPU or GPU.

- [PyTorch](pytorch.html) — the dominant training framework.
- [TensorFlow](tensorflow.html) — Google's framework, still widely used.
- [JAX](jax.html) — NumPy-style autodiff and XLA compilation.
- [ONNX Runtime](onnx-runtime.html) — portable cross-framework inference.
- [llama.cpp](llama-cpp.html) — lightweight CPU/GPU inference for LLMs.
