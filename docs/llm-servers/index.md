# LLM servers and inference platforms

Software that exposes language models as a service — usually with an OpenAI-compatible API — so they can be used by applications, agents and chat interfaces as a drop-in backend.

- [Ollama](ollama.html) — the easiest local model runner.
- [vLLM](vllm.html) — high-throughput GPU serving with continuous batching.
- [TGI](tgi.html) — Hugging Face's production inference server.
- [LocalAI](localai.html) — self-hosted OpenAI-compatible server without dedicated GPU.
- [LM Studio](lm-studio.html) — a desktop GUI for running models locally.
- [llama-server](llama-server.html) — the OpenAI-compatible server built into llama.cpp.
